# Prototipos y entregables

`docs/prototipos/` contiene propuestas HTML y variantes de interfaz; no todas corresponden a rutas o pantallas activas. El frontend vigente es la fuente para identificar la interfaz implementada.

`docs/entregables/` contiene documentos de curso/proyecto, entre ellos la guía práctica y el informe técnico individual. Son artefactos de entrega y contexto, no especificaciones ejecutables del backend. Contrastar cualquier dato funcional con los documentos temáticos y el código actual.
